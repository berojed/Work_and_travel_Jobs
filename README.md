## Features

- **User Authentication**: Secure user login and registration using Firebase Authentication.
- **Job Listings**: Browse and search for various job opportunities.
- **Application Tracking**: Keep track of all your job applications in one place.
- **Admin Portal**: Exclusive access for admin users to manage job listings and applications.
- **Real-time Updates**: Get instant updates on application statuses.

## Installation

Follow these steps to set up the project locally:

1. **Clone the repository**:
    ```bash
    git clone https://github.com/yourusername/work-and-travel-jobs.git
    ```

2. **Navigate to the project directory**:
    ```bash
    cd work-and-travel-jobs
    ```

3. **Install dependencies**:
    ```bash
    ./gradlew build
    ```

4. **Set up Firebase**:
   - Create a Firebase project at [Firebase Console](https://console.firebase.google.com/).
   - Add an Android app to your Firebase project.
   - Download the `google-services.json` file and place it in the `app/` directory.

5. **Run the app**:
    ```bash
    ./gradlew installDebug
    ```

## Usage

1. **Login/Register**: Use your email and password to register or log in.
2. **Browse Jobs**: Navigate through various job listings and filter based on your preferences.
3. **Apply for Jobs**: Click on a job listing to view details and apply directly through the app.
4. **Track Applications**: Monitor the status of your applications in real-time.
